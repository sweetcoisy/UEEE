# 前端演示

这是城市健康空间分析平台的静态前端演示，包含：

- 课题组介绍页面；
- 可扩展的模型中心；
- 15-15 健康绿地评估完整交互流程；
- 其他模型的开发状态与占位入口。

平台采用面向机构用户的三级信息结构：一级导航负责项目工作、模型目录与课题组信息；模型中心负责模型目录与接入状态；15-15 作为可达性模型进入独立工作台，不占用一级导航标签。任务和成果作为项目内部信息呈现，不再拆分重复入口。

项目工作台使用模拟项目数据集中展示指标、项目筛选、完整项目表和运行任务。15-15 页面采用 GIS 工作台布局：顶部功能带负责数据、模型、计算和输出命令，左侧图层树展示输入及结果数据，中央区域承载五步分析流程。

平台默认进入课题组介绍页。项目工作台、模型中心和课题组三个一级入口收纳在隐藏式侧边导航中，点击左上角 `UH` 标识打开，选择页面或点击遮罩后自动关闭。

课题组主页使用 `UEEE` 品牌，包含课题组定位、研究方向、负责人介绍、研究路径、代表工作、教育与任职以及加入团队等板块。余兆武老师的照片、职称、研究方向、公开履历和联系邮箱来自复旦大学环境科学与工程系公开教师主页。

演示中的上海地图来自 `paper_reproduction/outputs` 的实际复现结果。课题组正式名称、院校、成员与联系方式目前为待替换内容。

## 15-15 分析流程

页面按真实平台工作流组织为五步：

1. 创建分析项目，填写城市信息并上传研究边界、住宅区、绿地 AOI 和步行路网；
2. 检查数据质量、坐标系、必需字段，并配置字段映射和预处理选项；
3. 设置进入绿地、绿地内暴露和步行速度等模型参数；
4. 查看分阶段运行进度与处理日志；
5. 查看地图、指标和结果表，并下载报告、CSV、空间数据清单和运行摘要。

“一键载入上海样例”用于完整演示上述流程。当前版本是静态前端原型：用户上传文件的真实解析、GIS 预处理、异步任务调度、任意城市计算和服务端 PDF/GeoPackage 生成，仍需接入后端计算服务。

## 本地预览

在项目根目录运行：

```bash
python3 -m http.server 8080 --directory frontend_demo
```

浏览器访问：

```text
http://localhost:8080
```
